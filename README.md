# FIFA World Cup 2026 Prediction Model

A modular ML and simulation pipeline for the DataCamp FIFA WC 2026 Prediction Competition. Covers all 72 group-stage and 32 knockout matches, including resolved playoff teams.

## Quick start

```bash
cd FIFA_WC26_Model
pip install -r requirements.txt
python -m src.main --refresh-data   # first run: build all processed data
python -m src.main                  # subsequent runs (uses cached data)
python -m src.main --sim --n-sims 1000   # + Monte Carlo simulation
```

## CLI options

| Flag | Effect |
|------|--------|
| *(none)* | Offline run using cached processed data |
| `--refresh-data` | Force-rebuild all processed data (FIFA, Elo, pedigree, playoffs) |
| `--online` | Alias for `--refresh-data` (also triggers live fetch attempts) |
| `--sim` | Run Monte Carlo simulation after main predictions |
| `--sim --n-sims N` | Run simulation with N iterations (default 1000) |

## Rating model

Final rating is a source-driven weighted blend (0-100 scale):

| Source | Weight | Fallback |
|--------|--------|---------|
| FIFA points (normalised) | 35% | seeded |
| World Elo (normalised) | 25% | seeded |
| Recency-weighted form | 15% | seeded |
| Tournament pedigree | 10% | seeded |
| Seeded/manual | 10% | always present |
| Host advantage | 5% | binary |

Missing sources are reweighted proportionally among available sources.

## Audit

```bash
python -m src.audit_project
```

Checks file existence, placeholder leakage, rating component columns, output row counts, and playoff team presence.

## Tuning

- **Team ratings**: edit `SEEDED_RATINGS` in `src/ratings.py` (used as fallback regularisation)
- **Rating weights**: edit `_W` in `src/ratings.py`
- **xG parameters**: edit `BASE_XG`, `DRAW_RATING_THRESHOLD_GROUP`, `DRAW_RATING_THRESHOLD_KNOCKOUT`, `WC_CONSERVATISM` etc. in `src/config.py`
- **Late news**: add rows to `data/manual_overrides.csv`
- **Playoff results**: edit `data/external/playoff_results.csv`, then `--refresh-data`
